# Steganography 🖼️

Раздел с writeup-отчетами по стеганографии на платформе [Duckerz](https://duckerz.ru/).

В этой категории обычно встречаются:
- поиск скрытых данных в изображениях;
- анализ метаданных;
- работа с архивами и вложенными файлами;
- использование инструментов для стеганографии;
- поиск флагов в бинарных данных.
